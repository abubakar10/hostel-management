HOSTEL MANAGEMENT SYSTEM
What This System Does


This is an online system for running a hostel. Residents can check their fees and send requests from their phone. Managers can handle rooms, payments, staff, and daily work from one dashboard. Everything stays in one place instead of paper registers and WhatsApp messages.


WHO CAN USE IT

There are two main users.

Residents are students or people living in the hostel. They use the system to check fees, attendance, and to send complaints or leave requests.

Hostel managers are wardens or staff who run the hostel. They use the system to manage students, rooms, fees, attendance, mess, visitors, staff, and reports.

Super admins can manage more than one hostel and create manager accounts.


HOW TO LOG IN

Everyone uses the same login page. Residents log in with their Student ID or email. Managers log in with their username or email. After login, the system opens the right screen for that person. If you forget your password, you can reset it by email. The system also works on phone and computer, and you can install it like a normal app.


USING THE SYSTEM AS A RESIDENT


Dashboard

When a resident logs in, they see a simple home screen. It shows pending fees, attendance percentage, open complaints, and leave requests. From here they can quickly go to other pages.


Profile

Residents can view their name, student ID, email, phone, course, room, and hostel details. If something is wrong, they contact the hostel office to get it updated.


Fees

Residents can see how much fee they have paid and how much is still pending. They can also see the full fee history with due dates and payment status. Payment is done at the hostel office, and the manager records it in the system.


Attendance

Residents can see their attendance record. They can check how many days they were present or absent, their attendance percentage, and daily attendance details. They can also filter records by date.


Complaints

If something is wrong in the hostel, a resident can submit a complaint. They write the problem, choose a category like maintenance or cleanliness, and submit it. Later they can check if the complaint is open, in progress, or resolved.


Leave Requests

Residents can apply for leave when they need to go home or leave the hostel for some days. They select dates, write a reason, and submit the request. They can see later if the leave is approved or rejected.


Room Transfer

If a resident wants to change their room, they can request a room transfer. They can see available rooms and send a request with a reason. The manager will approve or reject it.


Notifications

Residents receive alerts about fee reminders, leave decisions, complaint updates, and hostel announcements.


USING THE SYSTEM AS A HOSTEL MANAGER


Dashboard

The manager sees a main dashboard with important hostel information. This includes total students, room occupancy, revenue, pending fees, open complaints, maintenance work, and attendance rate. It gives a quick picture of how the hostel is running.


Students

Managers can add new residents, edit their details, upload photos, search students, and remove records when someone leaves. The system supports students, job-based residents, and short-term residents.


Rooms

Managers can create and edit rooms, set room capacity and type, check which rooms are available or occupied, and assign students to rooms.


Fees

Managers can create fee records for hostel fee, mess fee, security deposit, and fines. They can mark fees as paid when a student pays, view receipts, and send reminders to students with overdue payments.


Attendance

Managers can mark daily attendance for all students as present, absent, or late. They can also mark everyone present at once and view monthly attendance reports.


Visitors

Managers can register visitors when they enter the hostel. They record visitor details, link the visit to a student, and check the visitor out when they leave.


Leaves

Managers can see all leave requests from students. They can approve or reject leave and add remarks if needed.


Mess

Managers can create daily mess menus for breakfast, lunch, and dinner. They can also record meal attendance and manage mess fee status.


Complaints and Maintenance

Managers can view and handle all student complaints. They can update complaint status, assign staff, and add resolution notes. They can also create and track maintenance jobs such as repairs in rooms.


Room Transfers

Managers can see room transfer requests from students. They can approve or reject them. When a transfer is approved, room details update automatically.


Staff

Managers can maintain a staff list with roles such as warden, cleaner, security, chef, and finance officer. They can add staff details, contact information, shift, and salary.


Inventory

Managers can track hostel items and supplies such as furniture, cleaning items, and kitchen stock. They can record quantity, location, condition, and purchase details.


Documents

Managers can upload and store student documents such as ID cards, admission forms, contracts, and photos. They can download or delete files when needed.


Reports

Managers can view financial reports including monthly income, expenses, and profit. This helps them understand how the hostel is performing financially.


Notifications

Managers can view system alerts, mark notifications as read, and manage important updates.


Super Admin Features

A super admin can manage multiple hostels, create manager accounts, and switch between different hostels from the top menu.


HOW THE SYSTEM HELPS IN DAILY WORK

In the morning, the manager can mark attendance and update the mess menu. During the day, visitors can be checked in, students can submit complaints, and maintenance work can be assigned. When a student needs leave, they apply from their phone and the manager approves it. For fees, the manager creates the fee, the student sees it in their account, pays at the office, and the manager marks it as paid. At the end of the month, the manager can check income and expenses in the reports section.


MAIN BENEFITS

For residents, the system gives easy access to fees, attendance, complaints, leave requests, and room transfer requests without visiting the office again and again.

For managers, the system brings all hostel work into one place including students, rooms, fees, attendance, mess, visitors, staff, inventory, documents, and reports.

For owners with more than one hostel, the super admin can manage all properties and users from one system.


DEVICE SUPPORT

The system works in a web browser on mobile, tablet, and computer. It can also be installed like an app on the home screen. It supports dark mode for easier viewing.

There is also a React Native app in the `mobile/` folder (Expo). Staff and residents use the same login and the same API as the website. See `mobile/README.md` to run it with Expo Go.


SUMMARY

This Hostel Management System helps residents stay informed and helps managers run the hostel smoothly. It reduces manual work, keeps records organized, and makes hostel operations easier to manage from one platform.
